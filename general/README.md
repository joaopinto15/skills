# General

Skills for thinking, interrogating ideas, and handing work over.

## User-invoked

Reachable only when you type them (`disable-model-invocation: true` in the frontmatter).

- **[grill-me](./skills/grill-me/SKILL.md)**: A relentless interview to sharpen a plan or design.
- **[grill-with-docs](./skills/grill-with-docs/SKILL.md)**: Grilling session that also builds your project's domain model, sharpening terminology and updating `CONTEXT.md` and ADRs inline.
- **[handoff](./skills/handoff/SKILL.md)**: Compact the current conversation into a handoff document for another agent to pick up.
- **[wait-what](./skills/wait-what/SKILL.md)**: Stop. That last message did not land: re-pitch it.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[grilling](./skills/grilling/SKILL.md)**: Grill the user relentlessly about a plan, decision, or idea. Use to stress-test thinking, or on any 'grill' trigger phrase.
- **[research](./skills/research/SKILL.md)**: Investigate a question against high-trust primary sources and capture the findings as a cited Markdown file in the repo, run as a background agent.
- **[unslop](./skills/unslop/SKILL.md)**: Cut AI tells from any writing. Always applies.
